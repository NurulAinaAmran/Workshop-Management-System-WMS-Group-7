# Workshop Management System (WMS)

## Project Overview
The Workshop Management System (WMS) is a mobile application developed as an academic group project
for the course BCS3133 (Software Engineering Practices) at Universiti Malaysia Pahang Al-Sultan Abdullah (UMPSA).

The purpose of this system is to digitalise and streamline workshop operations by providing a
centralised platform for workshop owners and foremen. The system reduces manual record-keeping
and improves efficiency in managing users, schedules, inventory, payments, and reports.
